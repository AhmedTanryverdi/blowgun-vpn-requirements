# blowgun.vpn - Requirements Repository

Репозиторий требований и аналитических артефактов для мобильного VPN-продукта **blowgun.vpn**.

> Статус: черновик требований (Draft)

## Цель продукта

Создать максимально удобное VPN-приложение, которое позволяет пользователю подключаться к VPN-серверам, выбирать сервер, управлять подпиской и просматривать профиль.

## Принятый технический контекст

- Mobile client: React Native
- VPN protocol: Xray
- Native/network component: C++
- Requirements and diagrams: Markdown + Mermaid
- Version control: Git

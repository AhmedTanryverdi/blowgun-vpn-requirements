# 8. Business rules

**Статус:** Draft

- **BR-001:** Учётная запись связывается с подтверждённым email. Сам по себе ввод адреса не доказывает владение им.
- **BR-002:** Повторный вход с подтверждённым email должен возвращать существующую учётную запись, а не создавать дубликат.
- **BR-003:** Доступ к серверу определяется backend на основе состояния учётной записи, подписки и политики доступа.
- **BR-004:** UI не является источником истины для статуса подписки; статус определяется backend/платёжной системой.
- **BR-005:** Повторная обработка одного и того же платёжного события должна быть идемпотентной.
- **BR-006:** Конфигурация VPN должна выдаваться только авторизованному пользователю и для разрешённого сервера.
- **BR-007:** Условия возврата, отмены и продления подписки должны быть определены до запуска оплаты.

## Требуют решения

- Доступен ли бесплатный тариф?
- Какие ограничения действуют для бесплатного/платного доступа?
- Что происходит с активным соединением при истечении подписки?
- Каковы правила отмены, возврата и восстановления покупок?

# 1. Product vision

**Статус:** Draft

## 1.1 Видение

blowgun.vpn — удобное приложение, в котором пользователь может быстро выбрать VPN-сервер, установить защищённое соединение и управлять доступом к платным возможностям.

## 1.2 Проблема

Пользователи регулярно сталкиваются с сетевыми ограничениями, которые блокируют доступ к привычным ресурсам — от мессенджеров для общения с близкими до профессиональных инструментов и информационных платформ. Когда нужный сайт перестает открываться, пользователь теряет связь с рабочим процессом и социальным кругом. Чтобы вернуть доступ, ему приходится искать сторонние инструменты. Однако существующие на рынке VPN-сервисы либо сложны в настройке и нестабильны, либо небезопасны. Пользователю нужен сервис, который незаметно интегрируется в повседневную рутину, обеспечивая надежный доступ к ресурсам без потери скорости и контроля над приватностью.

## 1.3 Целевая аудитория

- Пользователи мобильных устройств, планшетов и десктопов, которым нужен простой VPN-клиент.

## 1.4 Цели продукта

- **G-01:** пользователь может начать подключение без изучения технических настроек.
- **G-02:** пользователь может выбрать доступный сервер.
- **G-03:** пользователь может увидеть состояние VPN-соединения.
- **G-04:** пользователь может просмотреть статус подписки и способы оплаты.

## 1.5 Предлагаемый MVP

Включить:
- Авторизация по email через отправку одноразового кода;
- список доступных VPN-серверов;
- подключение и отключение Xray;
- отображение состояния соединения;
- профиль и статус подписки;
- экран тарифов/оплаты, если выбранный платёжный сценарий готов к реализации.

Не включать в первый релиз без дополнительного решения:
- сложную систему рекомендаций серверов;
- семейные планы;
- реферальную программу;
- несколько VPN-протоколов;
- расширенную аналитику пользовательского поведения.

## 1.6 Критерии успеха

Предлагаемые метрики:
- доля пользователей, успешно завершивших первое подключение;
- время от открытия приложения до успешного подключения;
- доля неуспешных попыток подключения;
- доля успешных входов;
- конверсия в платную подписку.

## 1.7 Ограничения и допущения

- Мобильное приложение разрабатывается на React Native.
- Для VPN-туннеля используется Xray.
- C++ рассматривается для сетевого/native-компонента;
- Наличие серверов, их регионы, экономика инфраструктуры и поддерживаемые платформы ещё не утверждены.

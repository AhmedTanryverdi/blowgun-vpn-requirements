# 3. Glossary

| Термин | Определение |
|---|---|
| VPN-туннель | Зашифрованный сетевой канал между устройством и VPN-сервером |
| Xray | Программная платформа для построения зашифрованных туннелей |
| VPN-сервер | Узел инфраструктуры, через который маршрутизируется трафик пользователя |
| Сессия | Период взаимодействия пользователя с приложением или авторизованное состояние; конкретное значение нужно уточнить в API |
| Подписка | Периодический или ограниченный по времени доступ к платным возможностям |
| Magic link | Одноразовая ссылка для входа, отправленная на email |
| OTP | Одноразовый код подтверждения |
| MVP | Минимальная версия продукта, позволяющая проверить ключевые гипотезы |
| Control plane | Сервис управления пользователями, конфигурациями, доступом и серверами |
| Data plane | Компоненты, которые фактически обрабатывают/маршрутизируют сетевой трафик |
